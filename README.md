# ServByteRestaurantApplication
**
A full restaurant service built with spring boot

**

**

The Front end code frontEndServByteApplication:

Ensure that you have node.js install in your system

also install angular cli.

After all these are installed then run the code with the command   ng serve -o.

The back end spring boot code can be run using any spring boot supported ide 


__Note__

Before running the front end code the back end code must be up and running
